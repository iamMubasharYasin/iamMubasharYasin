## 📅 My 30-Day .NET Challenge

I'm working through a structured learning roadmap to strengthen my ASP.NET Core backend development skills.

| Week | Focus |
| :--- | :--- |
| **Week 1** | ASP.NET Core fundamentals, controllers, routing, model binding, DI, middleware, configuration and CRUD APIs |
